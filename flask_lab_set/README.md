# Flask Lab Set (Templates + Forms + Static Files)

## Run
1. Activate your environment
2. Run: `python app.py`
3. Open: `http://127.0.0.1:5000/`

## Routes
- `/upper/<name>` -> uppercase
- `/lower/<name>` -> lowercase
- `/user/<username>` -> custom user webpage
- `/form` -> form + request object + template
- `/faculty` -> faculty table using Jinja2 loop
