# Flask + SQLite Student Form Lab

## Run
1. Open terminal in this folder.
2. Install Flask (if needed): `pip install flask`
3. Run: `python app.py`
4. Open: http://127.0.0.1:5000/

## Features
- Create table (`students`)
- Insert student form data
- Show all students in a table

## Viva Quick Answers
- SQLite: File-based lightweight DB.
- `sqlite3.connect()`: Opens DB connection.
- `CREATE`: Creates table.
- `INSERT`: Adds rows.
- `SELECT`: Fetches rows.
- `commit()`: Saves changes.
- `fetchall()`: Gets all results.
- `close()`: Frees DB resources.
